# TRANSMARQUES — WhatsApp Bot

Bot de atendimento automático da TRANSMARQUES usando Flask + WhatsApp Cloud API.

## Arquivos
- app.py — código principal
- requirements.txt — dependências
- .python-version — versão Python
- Procfile — comando para o Railway

## Variáveis necessárias no Railway
- WHATSAPP_TOKEN
- PHONE_NUMBER_ID
- VERIFY_TOKEN
- APP_SECRET
- GRAPH_VERSION

Nunca coloque os tokens diretamente no GitHub.
